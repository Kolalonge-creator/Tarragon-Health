# Audit: spec D.1 (connectivity and devices) and D.2 (language and accessibility)

Session S82, audit half. Branch `fix/content-approval-reviewer-role`. Read-only: no code changed, nothing committed, database untouched.

Scope: `apps/mobile` (the patient app, 79 section screens plus shell screens) and `apps/web` (66 patient dashboard pages, plus staff areas). Method: grep and file reads, plus a read-only jest run of `apps/mobile/src/ui`, `offline-queue`, `outbox`, `low-data`, `media-policy` (10 suites, 237 tests, all pass). Nothing was run on a device, so every "works on a phone" claim is marked not verified.

Superseded items, report only (decisions DG-1 to DG-6, OQ-252): the 40 MB install, 3 second cold start on 2 GB RAM and 1 MB daily data targets are not design constraints. Pidgin is removed (decision D-14, test `packages/db/tests/remove_pidgin_english_only.sql`). Voice logging is dropped (decision S47-1, `docs/DECISIONS.md:185`). Those are listed below as N/A, not as gaps.

Status key: MET, PARTIAL, MISSING, N/A (superseded by a recorded decision). Severity: High, Medium, Low. Size: S under a day, M one to three days, L more.

## Top gaps, in severity order

1. Audio is 0 percent live: 852 planned clips, none recorded, bundled map empty (item 17).
2. "What is this?" per screen and the 30 second tab tours have no UI at all (items 19, 20).
3. ListenButton is wired to 2 screens of about 79; results, lessons, reminders, onboarding and assistant replies have none (item 18).
4. Questionnaire answers for wellbeing, lifestyle, cycle and exercise screen are online only, no queue (items 3 to 6).
5. Half-typed form drafts exist on 4 forms only (item 10).
6. Low-data mode is a sync-size switch only: media policy has no callers, `profiles.low_data_mode` is never written, no Wi-Fi-only download path (items 13 to 15).
7. Touch targets under 44pt in legacy buttons and `SmallGhostButton`, and the scan cannot see them; text scaling capped at 1.2 in the top bar, drawer and tab labels (items 23, 24).
8. Hard-coded English strings in screens and no reading-grade gate (item 22).
