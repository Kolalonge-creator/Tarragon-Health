# S04 research (short; adapted, not copied)

- **1.13 Granular consent (Clue, Eka Care):** Clue asks consent per purpose and keeps each independently revocable; Eka Care gates record sharing per recipient. Adopt: one row per purpose, optional purposes default off, care consent is the only required one. Unsuitable: pre-ticked boxes, bundling research into care.
- **1.14 Plain-language summary (Clue):** short per-purpose sentences in the user's language, what is stored and who sees it. Adopt with en and pcm keys; Pidgin clinical wording needs native review (OQ-19). Audio is not in the repo yet.
- **1.15 History and withdrawal (CareClinic):** a dated list of what was granted and withdrawn, with one control to withdraw. Adopt as two taps. Unsafe: deleting history on withdrawal; keep it append-only.
- **1.16 Quiet hours and discreet wording (Flo Health):** generic notification text by default, optional quiet window. Deferred here (OQ-06 already mandates generic copy); `discreet_mode` exists, nothing reads it yet.
- **1.17-1.18 Dependants (Ovia Health, Nigeria-specific):** per-dependant permissions; hand-over at 18 needs the young person's own agreement. The live hand-over does not capture it (follow-up).
- **1.19 Set up for my parent (Nigeria-specific):** an adult child often holds the parent's phone or smartphone skills. Unsafe pattern to avoid: the child typing the code for the parent, or seeing anything before the parent agrees. Design answer: code goes to the parent's phone only, parent chooses what the child sees, 72 hour expiry, identical response whether or not the number already has an account.
