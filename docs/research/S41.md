## What a premium Tarragon version does and why

- One set of answers that Home, the plan preview and the questionnaire intro all read, so the person is asked once.
- Nothing about a condition is stored before the terms are agreed, and nothing is readable by staff through the API (INV-12 spirit).
- A programme code is eligibility and consent kept apart: joining is not sharing, and a code is not a coupon.
- Every failure of a code looks the same, so the box cannot be used to probe which codes exist.
