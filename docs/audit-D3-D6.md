Date: 2026-10-07. Branch `fix/content-approval-reviewer-role` (based on `origin/main-dev`). Method: code read in this worktree plus read-only SELECTs on live project `koiplnmbgnqnbywhpjlf`. Nothing was written or changed.

Caveats that apply to every row:
- The S39b/S39c audited-access work (`staff_record_opens`, `open_patient_record`, 128 tied tables) is APPLIED live but lives on branches `s39b/*`, `s39c/*` and is not in this worktree. Rows that depend on it say "live, not on this branch". Merge order (#997 then #1011) is a pre-condition for the repo and the live database to agree.

- Live counts are small (5 patients with consent rows), so "works live" is weak evidence about scale.
