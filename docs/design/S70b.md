## Decisions worth knowing
- **No new `vital_source` value.** The assisted-entry design note (section 2) records that a new value silently skips triggers keyed on manual/device. Pharmacy readings are `manual` plus the assisted-entry ledger (`pharmacy` / `counter_consent`), which the patient history already shows as "Entered for you ... at the pharmacy".
- **Display state is never a clinical state.** "Reconnect needed", "stale" and "estimate" change no number, grade or alert.
- **All numbers PROPOSED**: `bp.cuffless_calibration`, `devices.connection_health`, `pharmacy.reading_point` in the registry, mirrored to SQL by `s70b-mirror.test.ts`.
- INV-01: no model anywhere. INV-07: the task and visit text name no value or condition. English only; copy in `hub.*`, `cle.*`, `hbp.*`, `prd.*` (outside the reviewed-strings ledger scope).
