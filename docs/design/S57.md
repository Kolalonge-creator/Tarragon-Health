## Data model (migrations 20261007160143 onward, none applied to production)
1. `media_library` (global catalogue, no `organisation_id`, same precedent as `health_education_content`): kind (meditation, sleep_story, soundscape, breathing, exercise), exercise_type, series (fixed list), language, voice, duration_seconds, bytes, audio_url, audio_clip_id, script jsonb, creator_id, review fields (reviewed_by_name, reviewed_at, next_review_due), content_status, is_placeholder, is_active. One rule: servable = active, published, not a placeholder, review date not past (Africa/Lagos). Publish gate trigger. `media_library_config` (versioned PROPOSED: download caps, breathing bounds, sleep feedback epsilon), `media_sessions` (patient-only, ids), event `media.session_completed`.
2. Journal: `journal_sync_settings`, `journal_synced_entries` (ciphertext only). Patient-only RLS; no supporter category, no staff reader, break-glass does not reach it. Turning sync off deletes the server copies.
3. Sleep: `sleep_log_entries` + `sleep_latency_minutes`, `night_awakenings`; `sleep_wind_down_plans`; `sleep_apnoea_screen_config` (DRAFT v1, unsigned) and `sleep_apnoea_screens` (patient-owned; staff only through `read_patient_sleep_screens_audited`, tie or break-glass, audited).
4. Guards (seeded OFF): `sleep_apnoea_screen_enabled` (the questionnaire and its referral task), `wellbeing_library_clinical_scripts` (the exercises and breathing scripts, which are reviewed clinical content).

All wellbeing screens sit inside `SharedPhoneGate`. Mobile: library, session timer and breathing, journal, in the wellbeing screen.

## Safety rules
No model anywhere. Placeholders cannot publish. Expired items are not served (RLS and function level, proved with sabotage). Exercises are static reviewed scripts, never called therapy, always carry the fixed care-team and crisis note rendered by the template (not content). Breathing has the stop-and-seek-care note and no effect claim. No single sleep score and no restriction advice (a test on the weekly feedback keys). An unsigned instrument never creates a task. The journal's server copy is unreadable to everyone but the owner (and unreadable in content to anyone). Events carry ids only. No analytics or ad SDK on any new screen (scan extended).

## Go-live guards
`sleep_apnoea_screen_enabled` (CMO; conditions: instrument signed, referral cover confirmed). `wellbeing_library_clinical_scripts` (CMO; conditions: scripts reviewed). The library audio and meditation content is non-clinical wellbeing content like learning content and is gated by the publish gate, not a guard.
