## Data model (to build)
- `translations(key, language, text, state draft|native_reviewed|clinical_reviewed, source_hash, reviewed_by, reviewed_at)`, unique (key, language). A source change resets state to draft. Only the CMO moves a clinical key to clinical_reviewed.
- `automations(id, name, kind, schedule, owner_role, owner_user, runbook_url, last_run_at, last_status, enabled, guard_key)` mirrored read-only from `cron.job` and a static Vercel route list; owners added after.
- `ai_model_prices` (config, kobo), `ai_review_samples`.
- No new tables for CMS, directory, finance: columns only (`owner`, single `next_review_due`).

## Events (outbox only)
`content.published`, `translation.reviewed`, `automation.failed`. Register in `event_types`; none carry clinical text.

## Screens (one Governance area, extend existing pages)
Content and review-due queue; translations by state; KB versions with diff and regression run; directory and partners (reuse freshness page, add branches); support inbox with SLA clock; finance landing linking existing `/finance/*`; safety and data requests; automations; AI monitoring (cost, sample queue, reported answers). Every page gets a search entry (standing rule). Copy: English only, no em dashes, "your care team".

## Safety rules
Clinical content cannot publish without the CMO (DB-enforced, proved). Every inbound support message gets a deterministic red-flag scan before any reply (INV-01, INV-05). Notifications never name a condition (INV-07). Staff see only tied patients (INV-12, S39c). No AI output enters the record unsigned (INV-11). All test data `is_test`.

## Go-live guard
Enforce the five unenforced S37 guards (OQ-184), one sabotage proof each. Symptom checker stays off (decision 2, launch posture: emergency guidance and find-care only).

## Stage 1 conventions
RLS on every new table with a refused-role test; `source` and `recorded_by` where clinical; outbox events; PROPOSED config for review cadence (24/12 months), sample rate (5 percent), grace periods; guard per clinical feature.
