# S46d design note: yearly Health Report completion

Closes audited gaps in functions 3.12, 3.13, 3.15 (see S46 and S46c). Nothing is signed, no go-live guard changes, no audio is recorded.

- Charts and scorecards: `render-model.ts` builds `chart` and `gauge` data from the signed snapshot only (S43 `chartGeometry`). The web view and the react-pdf document draw the same geometry in black and grey. Each picture carries a sentence in words.
- Suggested recheck: `HealthReportConfig.retest` (settings v3, unsigned) -> `ReportItem.retestWeeks` and `ComposedReport.midYearRetestMonths` in the composer. No model.
- Phone: `apps/mobile/src/lib/health-report*.ts`, `HealthReportScreen`. A row is shown or saved only if it is signed with a signer, registration and signature time; a saved copy is re-checked on read.
- Share: section `health_report` of `record_shares`; body from `private.health_report_share_body` (latest signed only; risk band, questionnaires, reproductive screening, risk priorities, doctor's text, summary counts and blood-borne codes removed).
- Panel: `anti_hbs` add-on in `lab_panel_versions` v3. Optional, unpriced, no screen type.
- Audio: `packages/audio/src/report-audio.ts`, group RPT, draft slots; sensitive codes have no slot.
- Sign-off hub: report settings and serology rules panels; `sign_serology_rule_threshold`.
- Duplication note: `REPORT_EXCLUDED_CODE_PATTERN` (web), `REPORT_AUDIO_EXCLUDED_PATTERN` (audio) and `public.report_excluded_code` are the same list; tests pin the first two to the SQL.
