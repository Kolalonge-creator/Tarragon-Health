# S55 design note: Module 9, Health Learning Centre

Stacked on the F1 fix-first branch (the expiry gate is reused, not redone). Spec 9.1 to 9.8, lines 1232 to 1277. Research: `docs/research/S55.md`. Invariants in play: INV-07 (events carry ids only), INV-10 and INV-12 (a clinician reads a patient's saved lessons only with a tie, audited), INV-13 (`is_test`), INV-16 (versioned configuration). English only (D-14); see OQ-S55-01.

## 1. What exists and is reused
`health_education_content` (versions, status machine, reviewer fields, `audio_url`, knowledge check), programmes and modules, progress (seen, understood, needs_review), feedback, trigger recommendations, web `/patient/learn` and mobile `LearnScreen`, the F1 rule `private.health_education_is_servable()`, the S10 outbox (`emit_domain_event`), the S32 audio manifest and `getAudioService()`, `admin-search.ts`. Spec table names map onto these (`content_items` = `health_education_content`, `course_progress` = progress plus programme modules).

## 2. Data model (migrations `20261007140317_s55_learning_centre_foundation.sql`, `20261007141852_s55_learning_centre_functions.sql`)
- `health_education_content` + `audio_clip_id`, `self_care_action`, `is_micro_lesson`, `lesson_action`, `is_placeholder`, `share_enabled`, `creator_id`; programmes + `kind` (`course`/`series`).
- Publish gate trigger: named reviewer and review date, a source, a future `next_review_due`, a self-care step, a verified creator when credited, the micro-lesson shape (minutes and question count read from `learning_config`), never a placeholder.
- `learning_config` (versioned, PROPOSED): `micro_lesson`, `offline_pack`, `search_gap_log`, `search_synonyms`; mirrored in `packages/shared` proposed-config with a drift test.
- `learning_creators` (invite-only), `learning_search_gaps` (aggregate, no person), `learning_saved_for_consultation`.
- Events `lesson.completed`, `course.completed` (ids only; a trigger on progress; idempotent keys; a failure writes `audit_log` and opens an incident, never silent).
- Six DRAFT placeholders and the inactive myth-busting series.

## 3. Functions (all `revoke from public`; only `learn_shared_article` is anon-callable)
`search_health_education`, `health_education_item_trust`, `daily_micro_lesson`, `save_lesson_for_consultation`, `consultation_saved_lessons` and `mark_saved_lessons_discussed` (tie plus audit), `learn_shared_article`, `learning_offline_pack`, `learning_pack_status`, creator RPCs (`invite`, `submit_creator_credentials`, `verify` by a different admin, `suspend` taking content down), admin reports `learning_search_gaps_report` and `learning_readiness_report`. Every reader applies the F1 rule and hides placeholders.

## 4. Screens
Web: daily lesson card (Learn page and patient dashboard), search box, the fixed `LearningItemFooter` under every item (trust line, What can I do next, urgent-help box, share), clinician "saved lessons" card on the video visit screen, public `/learn/<code>` with a calm 404, admin pages `creators`, `readiness`, `search-gaps` (all in admin search) and new fields in the content form. Mobile: daily lesson card (Learn and Home), search, lesson viewer, footer, downloads card, refresh on return to the app.

## 5. Safety rules
Expired content is not served anywhere (extend of the F1 proof covers every new reader). Placeholders cannot publish. The urgent-help box and the ask/book actions are fixed template, not content. A failed refresh never empties the offline pack; the phone hides expired items itself. The share link carries only the content code. The search log holds no person. Nothing is signed by an agent: synonyms, caps, micro-lesson limits are PROPOSED.

## 6. Go-live guard
Content is non-clinical education already live today; no new clinical decision is made, so no new guard. Nothing new gates on `clinical_operations_enabled`. The myth series stays inactive until a clinical author writes it and the CMO approves.

## 7. Not built
Creator revenue share (OQ-S55-02), actual audio file download on the phone (OQ-S55-03), web audio playback of manifest clips, authoring UI for creators (Module 25 CMS, S80), real lesson content (clinical authors).
