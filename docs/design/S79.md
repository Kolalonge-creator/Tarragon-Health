## Data model (migration `20261027175329_s79_institution_console.sql`)
`institution_config` (versioned PROPOSED rules, mirrored in `packages/shared/src/proposed-config/institution-mirror`), `institution_programme_configs` (versioned requests, draft/submitted/approved/rejected), `usage_records` and `usage_statements` (write-once), `roster_upload_batches` and `roster_upload_rows` (raw values blanked after commit or cancel). Platform switch `institution_console` (OFF). No new person-level table is readable by a sponsor role: every table is revoked from users and reached only through SECURITY DEFINER functions that check `private.sponsor_staff_org()` or `private.can_manage_employer()`.

## Functions
Config: `institution_config_submit`, `institution_config_current`, `admin_review_institution_config`. Usage: `private.roll_up_usage`, `private.generate_usage_statements`, `sponsor_usage_statements`, `admin_link_usage_statement`. Pack: `sponsor_procurement_pack` (audits first, one `sponsor.staff_exported` row per programme, as `log_sponsor_staff_export` does). Ledger: `sponsor_privacy_ledger`. Upload: `employer_stage_roster_upload`, `employer_approve_roster_upload`, `employer_commit_roster_upload`, `employer_cancel_roster_upload`, `employer_roster_upload_report`. Codes: `enter_enrolment_code` (checks both, refuses an ambiguous code, shares the 10-per-hour guess limit), `admin_enrolment_code_overlap` (read only), plus triggers that stop a new code matching a code in the other table.

## Rules kept
I8 no capitation (nothing here prices by head). I9 and aggregate only: usage has no person column; statement lines under the minimum fold into "other"; pack uses frozen suppressed snapshots only; reproductive, pregnancy and mental health never appear (no source reads them; mental health only through `outcome_measure_cohort`, not used). Minimum cell via `private.suppress_cell` only. Money is integer kobo. Leaver handling calls `employer_mark_departed`, which ends the employer link and leaves the person's account and record untouched. Rewards budget is a requested number, never a balance (INV-09); the pool waits (OQ-S58-06 informational, OQ-S79-1).

## Guard and events
Module off by default (`platform_modules.institution_console`); each new function calls `private.assert_module_enabled`. Events not added to the outbox (OQ-S79-2: `cohort.enrolled` and `sponsor.report_generated` exist only as audit actions today).
