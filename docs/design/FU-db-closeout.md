## Built
- **A. One rota gap alert per organisation (S18 kept).** Two mechanisms raised the same fact: S18 `private.rota_gap_alert` (incident `rota_gap:<org>`, reviewers told, `rota.gap_detected` event; runs after every rota write and nightly) and SR5 rule `rota_gap_12h` (an `ops_alerts` row plus a second incident `ops_alert:rota_gap_12h:<org>:rota_gap`, every minute). `private.ops_check_rota_gap_12h` now returns no rows but calls S18's function for each organisation every minute, so the one incident is as fresh as the old alert was (a gap from leave, suspension or time off, which no rota write announces, is still seen within a minute); rule row, history and ACL kept. S18's function also raises a sev2 incident to sev1 when the gap becomes live. Existing open SR5 alerts and incidents are resolved quietly (no `ops_alert_notify`, no notice) and counted in the migration. S18's incident now resolves itself when cover is back (it never did), quietly. For an organisation whose gap was only visible through the SR5 rows, the migration calls `rota_gap_alert` once so a real gap stays visible: that is the one first notice of the merged alert (exception handler: a failure only warns, the nightly run covers it). Live today: 1 open SR5 alert, 1 open SR5 incident, 2 open S18 incidents.
- **B. Expired licence, suspended, offboarded, conflict, competency unchanged.

Closing asserts: no null left, the active row carries the date, the two stay eligible on 2027-01-13 and (without evidence) not on 2027-01-14 (Africa/Lagos). Registry versions 3, 4, 5 updated; the mirror test applies a marker line from the migration.
- **D. OQ-334.** `approve_triage_rule_set` refuses only for an active task type that needs confirmation, is unconfirmed AND answers a `create_task` key in that rule set. Every other check kept (CMO only, draft only, unanswered key, retire the previous approved version, audit row). Consequence: `crisis_follow_up` and `red_patient_outreach` (created by code, no rule key) never block a rule set; `amber_glucose_review` still blocks a glucose set until confirmed.
